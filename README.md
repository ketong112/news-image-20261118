A one-page newspaper front page summing up the world news of Wednesday 18 November 2026 — 35 stories on one page: 3 big illustrated leads (the Gulf strikes, Ukraine's hit on the Kerch bridge, the Xi–Putin–Trump summit at APEC Shenzhen), 6 more stories (Peltola's Alaska win and the 56–44 Senate, the Congo Ebola outbreak, Cyclone Akvan, falling stocks, the Gaza truce warning, Fiji's drought disaster), a by-the-numbers strip, a dotted world map with numbered pins, and 26 more one-line briefs from six continents. Drawn deterministically with Pillow by `draw_image.py`; `main.py` (Python 3.13, standard library only) copies the finished image to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
